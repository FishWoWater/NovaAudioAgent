- PRoot: OpenMinis/proot revision `1b444ee1cb2f4896c08166e9a12c905af5416f1c`, derived from Termux PRoot, GPL-2.0-or-later. Source is fetched and compiled by `build_runtime.py`.
- talloc 2.4.2: Samba, LGPL-3.0-or-later; linked statically into the GPL PRoot executable. Full source archive and its license are retained by the build script.
- ELF loader: Termux PRoot 5.1.107-70, distributed by OpenMinis/OpenMinis revision `b4c0661d5631ebab4d1a2e6f3fd4c805d4030a6c`, SHA-256 `44ef39c1e1a18c09f6e4c4b5d6f8bba82d30596598bd155ec162d05c5122ff04`. The OpenMinis build notes report vendor loader patches required on non-stock Android ROMs. Corresponding source: https://github.com/termux/proot/tree/4dba3afbf3a63af89b4d9c1a59bf2bda10f4d10f ; package recipe: https://github.com/termux/termux-packages/blob/0ff4d49dad73ed7a62375504cf96326bb835e132/packages/proot/build.sh . The build compiles this exact Termux source for the loader; the recorded vendor hash is a provenance reference, not a claim of byte-identical compiler output.
- Alpine Linux minirootfs 3.22.2 aarch64: official Alpine release archive. Individual package licenses and source are available from https://pkgs.alpinelinux.org/packages?branch=v3.22&arch=aarch64. The rootfs package database records installed versions. BusyBox is GPL-2.0-only; musl is MIT; apk-tools is GPL-2.0-only. Distribution requires providing corresponding source for included GPL components.
- Build flags and the talloc standalone compatibility shim are adapted from OpenMinis `deps/build_proot.sh` at the revision above, GPL-3.0. Runtime Kotlin and the process-group launcher are Nova code under the repository's GPL-3.0 license.

All download URLs and SHA-256 checksums are pinned in `build_runtime.py`. Build output includes a manifest and copies of available upstream license files. Keep source archives and build instructions alongside any distributed APK; retain the pinned loader source and package recipe with release evidence.
