# 原生视觉与监控验收

日期：2026-09-11。分支：`feature/native-vision-loop`。公共基线：`8018b623cabe892795d7b71c5e9a4d252be581a8`（`v0.2.0dev`）。改动仅在 `.worktrees/native-vision-loop` 本地，未合并、未推送。

## 已完成

- 删除内置相机 MCP、注册、设置项及图片转文字投影。对话视觉复用当前级联模型，默认关闭，未知模型与音频 realtime 不开放；固定默认摄像头。
- 语音和文本每轮采集一次原图，工具续答复用，后续轮次不重复携带；失败继续文字对话，取消和切换会话丢弃迟到结果。
- monitor/guard 独立绑定设备、采样、判断、报告、等待与释放；命中后继续，连续两次未命中重新布防。取消、超时、连续失败均结束并清理。
- 监控设备选择与刷新、独立监控模型配置；共享摄像头分别持有资源使用权，最后使用者退出才关闭设备。
- 保留 toggle、历史累计与本次启动用量。空卡片显示淡色「—」，只有一句空状态提示，无数据时隐藏明细；不恢复冗长说明。

## 实机与界面

macOS 本机摄像头测试通过：枚举到 2 个设备；默认设备取得 640 × 480 画面；对话与监控共享同一采集流；释放对话后监控仍可取帧；最后释放后轨道结束。真实渲染器会话协议完成 JPEG 二进制响应（本次 11054 字节）。图像仅留在内存，没有保存或发送给云端模型。

可在仓库根目录显式运行硬件检查：

```sh
node_modules/.bin/electron clients/desktop/scripts/native-camera-smoke.mjs
```

设置页通过浏览器预览检查了空用量卡片、提示与明细隐藏；该预览使用模拟用量数据。
