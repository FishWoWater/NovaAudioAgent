## 本地目录与 UI 验收

首轮只用目录元数据生成记忆，能够验证存储和展示，但不足以验证摘要质量。后续改为优先读取 README / overview / about / project 说明，在已有路径与内容筛查后提取有界正文；扫描统计仅保留在来源设置。

主机复用现有模型生成一段总览和最多四组摘要，组内带当前记忆 ID/版本引用。客户端拒绝陈旧引用；没有有效摘要时显示实际正文节选。来源变化、纠正或忘记会撤销旧摘要，失败可在后续刷新重试。

本地读取七份 README，写入隔离 VoiceMem，制作明确标注“本地整理示例”的四组摘要以验收实际 renderer。浏览器已检查摘要、关键词和展开依据入口；另修复 498px 窄窗口卡片被裁切的问题。此预览不等同于真实模型输出或已安装 Electron 验收。

首次 Qwen 摘要调用因外发授权被拦截；用户后续明确授权后已完成真实调用，结果见下方实测记录。

含本地目录名的截图、JSON、测试 SQLite 仅留在忽略的本地验收目录，不纳入公共提交。

## 阅读界面调整

摘要卡片默认仅显示正文与关键词；来源引用、依据入口和覆盖统计收进“连接与权限 → 调试 → 显示来源与依据”，默认关闭，仅当前窗口有效。页面底部“管理记忆”保留纠正和忘记，减少展开层级。正文改为 14px 并提高对比度。实际浏览器验证默认关闭、启用后显示、重新加载恢复关闭。

生成提示进一步约束短标题、两三句摘要和常见关键词；必要不确定性紧随事实，不在每组追加通用免责声明。本地整理预览同步精简，随后已替换为真实模型输出。

## 授权后真实模型验收

用户明确允许将选定的七份 README 节选发往已有阿里云 Qwen 服务。验收复用桌面 safeStorage，不记录密钥；输入、输出和临时数据库保留于忽略的本地目录。

- 实测发现原适配层只发 JSON mode，没有传递 schema；摘要调用现在显式把 schema 放入模型可见请求。
- 单次自由归纳出现遗漏、上游成果误归属、虚构集成关系。改为两步：逐条提取核心事实并校验 ID/version 一一对应；再分组、生成标题/关键词/总览。卡片正文按分组拼接已提取事实，模型不能只补引用却漏掉正文。缺项、重复、错版本、超长或失败均回退，最多两次调用，共用主机 30 秒期限。
- Qwen Plus 最终样本：七条主题全部进入正文，四张卡片，每卡最多三个关键词；两次请求合计 26.9 秒。分支工作、上游归属、演示方案及不同项目关系经独立 review 通过。实际 renderer 已显示原始模型结果，默认无依据/来源入口。
- 默认 Qwen Flash 在本样本中表现不稳定，多次未通过结构或内容验收；Plus 对照通过不代表 Flash 通过，也不代表长期生成质量已保证。未修改全局或持久模型配置。
- 当前摘要回归 10/10，编译、相关 lint、Node parity 检查通过。界面目标验收通过；端到端已安装客户端、默认 Flash 质量和更广样本验收仍分别记录，不据此宣称发布就绪。

### 2026-09-12 决策

1. 记忆收敛为一套三阶段底座：账本只追加且**存原文**，条目是修订日志，视图只读。VoiceMem 与 Workspace Graph
   变成写入方，不再各自为真。用户纠正和模型合并是同一种修订记录。详见 [00 卷 D8](00-overview.md) 与 [06 卷](06-memory-substrate.md)。
2. 飞书 IM 与邮件都在本版范围：飞书既是来源也是提醒投递渠道，必须是部署时配置的通用连接器。
3. 已实现的 M6-A（VoiceMem Worker 内的 ID / 版本 / 纠正 / 忘记）是过渡形态，接口语义与 06 卷一致，不推翻。

4. 原文归 A，Knowledge 退为分块/FTS/embedding 索引；统一回忆属于 06 卷 C 阶段，继承显式外发同意，关闭原“知识库与账本关系”待拍板项。
5. cascaded 增加可关闭的预检索，与 ASR 重叠并在注入前校验；integrated 只保留显式回忆。两条管线仍共用回复偏好。
6. 本轮以原生 TS 抽取和 merge 实现底座；旧 VoiceMem 只读迁入并保留原库。飞书先实现选定会话采集及默认关闭的本人私聊 bot，原文默认 30 天。
