# Mac 与 Android：Hub 扫码连接

此功能连接的是个人数据同步 Hub（`/hub/v1`），不是原生 iPhone 的语音主机（`/client/v1`）。首版支持 macOS 与 Android；已有高级手动连接保持兼容。

## 使用

1. 将 Nova 安装到 Mac 本机。在 Mac 和 Android 安装 Tailscale，登录同一 tailnet，启用 MagicDNS / HTTPS，确认访问策略允许设备访问 Mac 的 8443 端口。
2. Mac 设置 → **手机同步 Hub** → **启用后台同步**。应用启动用户级后台服务并配置 Tailscale Serve 8443。443 上已有服务不会改变；端口冲突或 Funnel 配置会阻止生成二维码。
3. Android 连接设置 → 填写本机名称 → **扫描 Mac 二维码**。核对显示的主机地址，确认后保存连接并开始同步。
4. 二维码五分钟有效、只能兑换一次。刷新、取消、正常退出桌面应用以及后台 Hub 重启会使相应邀请失效。连接成功后设备凭据保存在手机安全存储中。

退出 Nova 后 Hub 仍运行，用户下次登录时自动启动。Mac 休眠、注销或离线期间不保证可连接。Android 通常只能同时使用一个 VPN；请自行处理其他 VPN 与 Tailscale 的冲突，Nova 不会关闭其他 VPN。

多手机共享这个 Hub 的账号，每账号最多 32 台未撤销设备。Mac 可查看与撤销设备，即使 Tailscale 暂时断开仍能撤销。撤销后后续请求被拒绝，手机本地资料保留。已绑定其他账号或 Hub 的本地资料不能直接切换，不提供自动迁移或清空。

## 后台服务与恢复

- 生产服务使用用户级 LaunchAgent `ai.deepnovacore.nova.hub`，数据目录 `~/.nova/hub-desktop/`。开发环境有独立服务名及数据目录后缀，不接管旧 CLI 的 `~/.nova/hub/`。
- HTTP 仅监听 `127.0.0.1:8787`。管理请求只通过数据目录内的 `admin.sock`，目录权限 0700，socket 和文件 0600；没有 HTTP 管理令牌或管理路由。
- **停止后台同步**停止进程并取消登录启动；**移除后台服务**再移除服务登记，均保留数据库。重新启用复用原账号、Hub 身份和设备。
- 网络清理失败不会阻止停止服务；界面保留提示，网络恢复后可再次移除。只移除本功能记录且当前配置仍精确匹配的 8443 映射，不使用 `serve reset`。
- 手动替换应用包前先停止后台同步；更新后重新启用。已有服务在应用启动时会检查版本及可执行路径并重新登记。项目当前没有自动更新器，因此没有自动更新前的停机钩子。
- 端口被已有 Hub 占用时不会自动接管或覆盖。不要删除旧数据库来排除端口问题。

## 协议与边界

二维码字段：`type: nova.hub`、`version: 1`、`url`、`code`、`expires_at`（Unix 毫秒）、`hub_id`、`account_id`。二维码仅包含一次性凭据，不包含设备令牌。新扫码流程只接受 Tailscale HTTPS 主机；不接受 userinfo、查询参数、fragment、额外路径或跳转。

`POST /hub/v1/pairing/redeem` 接收 `code`、`device_name`、`hub_id`、`account_id`，返回该设备的身份及独立令牌。邀请码与令牌在数据库中仅保存哈希；消费邀请与注册设备在同一事务内。该路由是唯一无需设备认证的 HTTP API，限 4 KiB 请求体、5 秒读取期限、8 个并发请求、全局 60 次/分钟。普通设备不能创建邀请或撤销其他设备。

管理 socket 使用 `POST /admin`，操作为 `status`、`invite`、`cancel`、`devices`、`revoke`。其权限来自私有目录和当前系统用户，不向渲染进程提供管理凭据。

手机兑换后还会校验实际同步状态中的 Hub/账号身份，再原子保存连接。响应丢失或安全存储失败时，可能已经注册了设备但手机未保存凭据；重新生成二维码，并在 Mac 撤销残留设备即可。首次同步在连接保存后异步继续，不阻止用户离开页面。

## 验证

自动化覆盖真实 Hub 子进程、私有 Unix 管理、HTTPS 代理、Flutter 配对与 Todo/Idea/Goal 同步、撤销后的 401、本地数据保留；另有邀请码过期/取消/并发、设备上限、慢请求/限流、崩溃恢复和桌面生命周期回归。

这些测试使用合成账号、临时数据库和临时证书，不代表真实 tailnet、Android 相机、真机 VPN 切换或 Mac 登录/注销均已验收。当前构建和测试证据见 [实施记录](HUB-PAIRING-IMPLEMENTATION.md)。
