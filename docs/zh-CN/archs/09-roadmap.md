# 路线图

Nova 已提供实时对话、后台执行、视觉监控、个人记忆、知识库和 iPhone 客户端。当前兼容范围见[支持矩阵](../support-matrix.md)。

接下来主要探索三个方向：

- **更多编码后端。** 在 Codex 之外接入 Kimi Code、pi agent，复用项目管理、审批、进度和取消机制。
- **GUI-use。** 将图形界面任务交给专门的智能体，明确设备选择、操作权限和执行结果。
- **更有用的主动协助。** 结合已授权的数据来源和个人记忆，发现值得跟进的事情。推断出需求不等于获得执行许可。

以上是规划方向，不代表已经支持，也不构成发布时间承诺。各后端的兼容范围会单独说明。
